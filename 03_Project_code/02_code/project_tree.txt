================================================================================
子项目区别说明（03_Project_code 内各固件项目对比）
================================================================================

这五个项目是同一套伺服固件代码库，针对不同上位机接口编译出的不同固件镜像，
核心控制算法完全共享，区别只在通信层和产品定制层。

一览对比表
----------
  项目            产品型号   上位机接口                  编译宏                    轴数   固件码
  02_SGD7S_AP     SGD7S      模拟量电压 + 脉冲序列        NETIF_ANLGPLS_TYPE        1轴    —
  03_SGD7S_M2     SGD7S      MECHATROLINK-II              NETIF_M2_TYPE             1轴    —
  04_SGD7S_M3     SGD7S      MECHATROLINK-III             NETIF_M3_TYPE             1轴    0x02250000
  05_SGD7S_CM     SGD7S      Custom Motion（DPM总线）     NETIF_CM_TYPE             1轴    —
  06_SGD7W_M3     SGD7W      MECHATROLINK-III             NETIF_M3_TYPE+CSW_SGD7W   2轴    0x02250001

共享的部分（完全相同）
----------------------
  00_Bsp/JL086_bsp/        ← BSP 层完全相同（同一颗 JL086A SoC）
  01_Standard/
    BaseControls/           ← 伺服控制算法完全共享（位置环/速度环/振动抑制/前馈...）
    BaseSequences/          ← 运行序列完全共享（使能/报警/电源管理...）
    Kernel/                 ← OS 内核完全共享

  ScanB 基础周期全部相同：125μs

不同的部分
----------
① 通信层（核心区别）

  02_SGD7S_AP → Communications/AP/
      ├── ScanN/          ← 模拟量/脉冲轮询接口（不走网络总线）
      └── Motion/         ← 本地运动控制

  03_SGD7S_M2 → Communications/M2/
      ├── Mlink/          ← MECHATROLINK-II 链路层（17字节帧，2.5Mbps）
      └── Motion/

  04_SGD7S_M3 → Communications/M3/
      ├── MLink/          ← MECHATROLINK-III 链路层（32/64字节帧，100Mbps以太网物理层）
      └── Motion/

  05_SGD7S_CM → Communications/DPM/
      ├── Mlink/          ← 双口RAM总线（内嵌运动控制器，如上位PLC直连）
      ├── Motion/
      └── SC_UartDrv.c    ← 串口驱动（CM型有独立串口调试接口）

  06_SGD7W_M3 → Communications/M3/
      ├── MLink/          ← 同 M3，但需处理双轴数据打包
      └── Motion/

② 产品定制层

  02_Custom/00_SGD7/
    01_SGD7S_AP/    ← AP型特有：模拟量输入处理、脉冲指令解码
    02_SGD7S_M2/    ← M2型特有：M2报警码映射、M2参数寄存器表
    03_SGD7S_M3/    ← M3型特有：M3命令集、SystemSetting.h（CSW_NETIF_TYPE=NETIF_M3_TYPE）
    04_SGD7S_CM/    ← CM型特有：DPM接口映射、CM命令集
    05_SGD7W_M3/    ← W型特有：双轴资源管理（MAX_AXIS_NUMBER=2，SERVO_FIRM_CODE=0x02250001）

③ SGD7W（06）与其他最本质的差别

  SGD7W 是双轴驱动器，需要在同一颗 SoC 上同时运行两套伺服控制循环：

    // 04_SGD7S_M3（单轴）
    #define MAX_AXIS_NUMBER   1
    #define CSW_BOARD_TYPE    SGD7S_TYPE

    // 06_SGD7W_M3（双轴）
    #define MAX_AXIS_NUMBER   2          // 两套 AXIS_HANDLE
    #define CSW_BOARD_TYPE    SGD7W_TYPE
    // 额外编译宏: CSW_SGD7W_TYPE        // 控制双轴相关的条件编译分支

架构示意
--------

  ┌─────────────────────────────────────────────────────┐
  │                   JL086A SoC                        │
  │                                                     │
  │  ┌─────────────────────────────────────────────┐    │
  │  │  ASIP（微运算处理器）  电流环  62.5μs        │    │
  │  └─────────────────────────────────────────────┘    │
  │                                                     │
  │  ┌──────────┐  ┌──────────┐  共享                  │
  │  │BaseCtrl  │  │BaseSeq   │  ScanB 125μs            │
  │  │(速度/位置)│  │(状态序列)│  ←── 5个项目完全相同   │
  │  └──────────┘  └──────────┘                        │
  │                                                     │
  │  ┌──────┬──────┬──────┬──────┐  ← 通信层各自不同   │
  │  │  AP  │  M2  │  M3  │ DPM  │                     │
  │  │模拟  │ML-II │ML-III│CM总线│                     │
  │  └──────┴──────┴──────┴──────┘                     │
  └─────────────────────────────────────────────────────┘
          ↑AP型    ↑M2型   ↑M3/W型  ↑CM型
       脉冲/模拟  网络总线  网络总线  内嵌控制器

  结论：一套控制算法，四种总线接口，编译时通过 CSW_NETIF_TYPE 宏切换；
        SGD7W 额外增加双轴支持（CSW_SGD7W_TYPE + MAX_AXIS_NUMBER=2）。

================================================================================
架构要点总结
================================================================================

  层次              内容
  ──────────────    ────────────────────────────────────────────────────────────
  硬件平台          安川自研 JL-086A SoC（ARM Cortex-R4F，实时处理器）
  编译工具链        ARM DS-5 IDE（Eclipse CDT + ARM GCC/armcc）
  多核分工          AP核（应用层） + M2/M3核（通信协议） + 微运算ASIP（电流控制）
  产品型号          SGD7S（单轴）× 4种接口 + SGD7W（双轴）× M3
  固件分层          BSP → Kernel → Standard（Controls + Sequences + Communications）→ Custom
  固件输出格式      .boot（引导） / .firm（固件） / .mir（镜像备份） / .rtm（运行时）
  PC仿真            Visual C++ 仿真项目（MercurySimulation.sln）
