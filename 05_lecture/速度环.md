# 安川 Sigma-7 速度环：理论推导、参数整定与代码实现

---

## 一、被控对象建模

速度环的被控对象是电机轴的转动力学方程：

$$J \cdot \frac{d\omega}{dt} = T_q - T_f - T_L$$

| 符号 | 含义 |
|------|------|
| $J$ | 总转动惯量 [kg·m²]（电机转子 + 负载） |
| $\omega$ | 转子角速度 [rad/s] |
| $T_q$ | 电磁转矩（由电流环产生） |
| $T_f$ | 摩擦转矩（粘性摩擦 $B \cdot \omega$） |
| $T_L$ | 负载扰动转矩 |

对电流环做理想化假设（带宽远高于速度环，相当于增益=1）：

$$T_q(s) \approx K_t \cdot I_q(s)$$

忽略摩擦和负载扰动，得到速度对象的传递函数：

$$G(s) = \frac{\omega(s)}{T_q(s)} = \frac{1}{J \cdot s}$$

这是一个**纯积分环节**，这正是为什么速度控制器需要有比例项来提供阻尼的原因。

---

## 二、速度环控制器结构

安川 Sigma-7 的速度环采用 **PI 控制器**（含 I-P 变种）：

### 标准 PI 控制

$$U(s) = K_v \left[1 + \frac{1}{T_i \cdot s}\right] E(s) = K_v \cdot E(s) + K_{vi} \cdot \frac{E(s)}{s}$$

### I-P 控制

$$U(s) = \frac{K_{vi}}{s} \cdot R(s) - K_v \cdot Y(s) - \frac{K_{vi}}{s} \cdot Y(s)$$

**目的**：消除速度指令突变时的超调——比例项不跟踪阶跃指令尖峰，只有积分项响应指令，比例项仅作用于反馈误差。

### 完整速度环信号流

```
NetSpdRef ────────────────────────── [+] ──→ Kv, Kvi ──→ TrqRef ──→ CurrentLoop
                    ↑                  │
                 SpdFFC               [−]
                (速度前馈)              │
                                  SpdObsFbki
                              (速度反馈，经低通滤波器)

SpdFBC (扰动观测器) ──→ 加到速度反馈
TrqFFCx (转矩前馈) ──→ 直接叠加到 TrqRef（绕过 PI）
```

## 三、参数推导

### 3.1 归一化参数 Kvx（`BprmCalc.c`）

$$K_{vx} = \frac{2\pi \cdot \omega_{max} \cdot J}{T_{max}}$$

```c
// BprmCalc.c: ~960行
fw = Bprm->OvrSpd * C2PAIE7 / C10POW7;   // 2π·ω_max
Bprm->Kvx = fw * Bprm->Jmot / Bprm->MaxTrq;
```

**物理意义**：Kvx 是归一化的"1 Hz 速度带宽对应的增益系数"。它把电机的物理参数（$J$、$T_{max}$、$\omega_{max}$）合并为一个无量纲的基准增益，使后续的用户参数（loophz、jrate）直接以工程量操作。

### 3.2 比例增益 Kv（`BaseControlPrmCalc.c`）

**PI 控制模式**：

$$K_v = K_{vx} \cdot \frac{(100 + \text{jrate}) \cdot \text{loophz}}{1000}$$

```c
GselGains->Kv = MlibScalKskxkx( Bprm->Kvx, (100+jrate)*Loophz, 1000, NULL, 24 );
```

**I-P 控制模式**（`PI_rate = (100 - ipg_rwt)/100 < 1`）：

```c
GselGains->Kv  = 1;                       // 比例项归一化为1
GselGains->Kv2 = MlibScalKskxkx( Bprm->Kvx, (100+jrate)*Loophz, 1000, NULL, 24 );
```

**带宽推导**：

$$\omega_{bw} = \frac{K_v}{J} = K_{vx} \cdot \text{loophz} \cdot 2\pi$$

设 loophz = 40 Hz，则速度环带宽约 40 Hz（Kvx 已包含 $J$ 的归一化）。

### 3.3 积分增益 Kvi（`BaseControlPrmCalc.c`）

$$K_{vi} = K_v \cdot \frac{T_s}{10 \cdot T_i}$$

```c
// KPI_MBCYCLEUS = ScanB 周期 [μs]（250μs 或 500μs）
// Pitime = PnB02，速度积分时间常数 [×0.1ms]
GselGains->Kvi = MlibScalKskxkx( GselGains->Kv, KPI_MBCYCLEUS, 10*Pitime, NULL, 24 );
```

离散积分等效：

$$I_{out}[k] = I_{out}[k-1] + K_{vi} \cdot e[k] \cdot T_s, \quad K_{vi,\text{continuous}} = \frac{K_v}{T_i}$$

### 3.4 速度反馈滤波器 KVfbFil

对速度反馈施加一阶低通滤波器：

$$H(z) = \frac{1 - \alpha}{z - \alpha}, \quad \alpha = e^{-\omega_f T_s}$$

**目的**：抑制编码器量化噪声。提高 loophz 时需同步提高滤波带宽，否则相位裕度损失导致振荡。

### 3.5 负载惯量比 jrate（PnB01）

$$\text{jrate} = \frac{J_{load}}{J_{motor}} \times 100\ [\%]$$

在增益计算中：

$$J_{total} = J_{motor} \cdot \left(1 + \frac{\text{jrate}}{100}\right), \quad K_v = K_{vx} \cdot \left(1 + \frac{\text{jrate}}{100}\right) \cdot \text{loophz}$$

自动整定（TuneLess）会在线估计 jrate，结果存储在 `TuneLessPrm->jrate`。

## 四、速度反馈来源

速度反馈不是直接使用编码器脉冲微分，而是来自 ScanA 级别的观测器计算输出（`CtrlLoopOut->MotSpd_a`）：

```c
// BaseControls.c: ~510行
BaseControls->CtrlCmdMngr.SpdFbki    = CtrlLoopOut->MotSpd_a;
BaseControls->CtrlCmdMngr.SpdObsFbki = CtrlLoopOut->MotSpd_a;
```

`MotSpd_a` 在 ScanA 中通过编码器位置差分和低通观测器计算，单位为归一化速度（满速 = `0x01000000` = $2^{24}$）：

$$\text{MotSpd}_{normalized} = \frac{\Delta\text{Position}_{ScanA}}{T_{s,ScanA}} \cdot K_{motspd}$$

速度反馈在送入 PI 前，还经过低通滤波器：

```
SpdFbFilo = LPF( SpdObsFbki + SpdFBC, KVfbFil, SpdFbFilo_prev )
```

## 五、代码实现详解

### 5.1 速度控制主函数（`BaseLoop.c:387~622`）

函数：`BaseSpeedControl( BASE_LOOPCTRLS *BaseLoops, SpdFFC, SpdFBC, BaseEnable )`

**Step 1 — 速度指令选择**

```c
if (BBRefClrReq)         SpdRefo = 0;             // BaseBlock 时清零
else if (CtrlMode==SPD)  SpdRefo = SpdRefi;        // 速度控制模式
else if (CtrlMode==ZCLMP) SpdRefx = ZeroPositionControl();  // 零箝位
```

**Step 2 — 相位超前补偿（TuneLess 激活时）**

```c
d_SpdRefx = LpxSpdRefPhaseComp( SpdRefx, SpdRefPhFil, SpdRefPhFilGn );
// 形式：相位超前 = LPF(ref) + gain × HPF(ref)
// 目的：补偿速度反馈低通滤波器引入的相位滞后
```

**Step 3 — P/PI 模式切换（`ModeSwitch()`）**

根据 PnB03 设置，在以下条件之一成立时切换为 P 控制：
- 转矩指令超过阈值
- 速度指令超过阈值
- 加速度超过阈值
- 位置偏差超过阈值

**Step 4 — P 控制分支**

```c
// BaseLoop.c: ~544行
SpdFbFilo = MlibLpfilter1( SpdObsFbki + SpdFBC, KVfbFil, SpdFbFilo );
SpdErrP   = SpdRefx - SpdFbFilo + SpdFFC;
PacOut    = MlibMulgain( SpdErrP, GselGains->Kv );

// 积分不保持，而是以时间常数软衰减（见第六节抗饱和部分）
IacOut = MlibLpfilter1( 0, KVintegFil, IacOut );
```

**Step 5 — PI 控制分支**

```c
// BaseLoop.c: ~578行
SpdFbFilo = MlibLpfilter1( SpdObsFbki + SpdFBC, KVfbFil, SpdFbFilo );

// I-P：比例项乘 PI_rate（<1），抑制指令跳变超调
SpdErrP = MlibMulgainNolim( SpdRefx, PI_rate ) - SpdFbFilo + SpdFFC;
PacOut  = MlibMulgain( SpdErrP, GselGains->Kv );

// 积分使用完整误差（不乘 PI_rate）
SpdErrI = SpdRefx - SpdFbFilo + SpdFFC;

// 抗积分饱和门控（见第六节）
if ( (FALSE == TrqClamp) || (neri_calc_on == TRUE) ) {
    IacOut = MlibIntegral( SpdErrI, GselGains->Kvi, Ivar64 );
}
```

**Step 6 — 输出合成**

```c
// BaseLoop.c: ~615行
TrqRef0 = PacOut + IacOut;
TrqRef  = MlibMulgain29( TrqRef0, GselGains->Kv2 );  // I-P 模式 Kv2≠1
```

### 5.2 离散积分实现（`MlibIntegral`）

采用 64-bit 累加器防止溢出：

```
Ivar64 += SpdErr × Kvi       // 64-bit 累加
IacOut  = Ivar64 >> 1        // 取高 32-bit 作为输出
```

等效连续域：$I_{out}(s) = \frac{K_{vi}}{s} \cdot E(s)$

### 5.3 低通滤波器实现（`MlibLpfilter1`）

一阶 IIR 低通：

$$y[k] = (1 - \alpha) \cdot x[k] + \alpha \cdot y[k-1]$$

滤波系数 $\alpha$ 通过 `MlibPcalKf1gain()` 计算：

$$K_f = 2^{24} \cdot (1 - e^{-\omega_c T_s})$$

## 六、积分抗饱和（Anti-windup）

安川速度环有**两套**抗饱和机制，分别对应 PI 控制和 P 控制两个分支。

### 6.1 PI 控制分支——条件积分门控（`BaseLoop.c:527~603`）

**Step 1：检测"回程条件"（neri_calc_on）**

```c
// 速度误差符号与转矩输出符号相反 → 积分器正在从饱和方向退出
if ( ( (SpdRefx - SpdObsFbki >= 0) && (TrqRef < 0) )
  || ( (SpdRefx - SpdObsFbki <  0) && (TrqRef > 0) ) )
    neri_calc_on = TRUE;
else
    neri_calc_on = FALSE;
```

**Step 2：饱和门控（条件积分法）**

```c
if ( (FALSE == TrqClamp) || (neri_calc_on == TRUE) ) {
    IacOut = MlibIntegral( SpdErrI, Kvi, Ivar64 );
}
// else: Ivar64 不变 → IacOut 冻结，积分停止
```

| 条件 | 含义 |
|------|------|
| `TrqClamp == FALSE` | 转矩未饱和，正常积分 |
| `neri_calc_on == TRUE` | 虽然饱和，但积分方向正在帮助退饱和，允许继续 |

这是经典的**条件积分法**（Conditional Integration），比硬截断更平滑，不会在饱和边界产生抖动。

### 6.2 P 控制分支——软衰减（LPF toward zero）

P 控制（I-P）分支的积分不用门控，而是用低通滤波器让积分量缓慢衰减：

```c
IacOut = MlibLpfilter1( 0, KVintegFil, IacOut );
// y[k] = α × y[k-1]  →  指数衰减趋向零
Ivar64[1] = IacOut << 1;
Ivar64[0] = 0;
```

每个控制周期积分量乘以 $\alpha$（$< 1$），指数衰减趋向零。避免了硬复位的冲击，也防止了饱和时积分量无限积累。

## 七、前馈补偿

### 7.1 速度前馈（SpdFFC）

**内部来源**：位置指令一阶差分 × `KdPff` 增益，经低通滤波后加入速度指令：

```c
// BaseControls.c: ~873行
SpdFFx = MlibMulgain( PosManager->dPosRefi, BaseControls->CtrlCmdPrm.KdPff );
BaseControls->CtrlCmdMngr.dPFfFilo = MlibLpfilter1( SpdFFx, KdPffFil, dPFfFilo );
BaseControls->CtrlCmdMngr.SpdFFCx += BaseControls->CtrlCmdMngr.dPFfFilo;
```

**外部来源**：Mechatrolink 上位机下发 `NetSpdFFC`，经移动平均滤波后叠加：

```c
SvControlIf->NetSpdFFC = FFcmdFilMoveAverageFilter( &VFFcmdFil, NetSpdFFC, vffFilSts );
BaseControls->CtrlCmdMngr.SpdFFCx += SvControlIf->NetSpdFFC;
```

**作用**：减小跟踪误差，实现对阶跃位置指令的零稳态误差。

### 7.2 转矩前馈（TrqFFC）与加速度前馈

转矩前馈**绕过 PI 控制器**，直接叠加到转矩指令，补偿惯量加速所需转矩：

$$T_{FF} = J_{total} \cdot \frac{d^2\theta_{ref}}{dt^2}$$

安川有三条路径生成 TrqFFC，取决于工作模式：

#### 路径 A：外部（Mechatrolink 上位机）

上位机在 CSP/CST 模式下根据轨迹规划计算 $T_{FF} = J_{total} \cdot \alpha_{cmd}$ 并通过 `NetTrqFFC` 字段下发：

```c
// BaseControls.c: ~904行
SvControlIf->NetTrqFFC = FFcmdFilMoveAverageFilter( &TFFcmdFil, NetTrqFFC, tffFilSts );
BaseControls->CtrlCmdMngr.TrqFFCx += SvControlIf->NetTrqFFC;
```

移动平均滤波器（`FFcmdFilMoveAverageFilter`）平滑上位机离散指令的阶跃冲击。

#### 路径 B：内部 MFC（Model Following Control，模型跟随控制）

**适用场景**：内部点对点（ProgramJog/TableDrive）模式，无上位机介入。

MFC 在 `PosManager.c:381~384` 处被调用，同时输出 `SpdFFCx` 和 `TrqFFCx`：

```c
dPosRefo = MfcControlMain( &(BaseControls->MFControl),
                            BaseControls->CtrlCmdMngr.dPcmdFilo,
                            &(BaseControls->CtrlCmdMngr.SpdFFCx),
                            &(BaseControls->CtrlCmdMngr.TrqFFCx) );
```

**MFC 内部计算（刚体模型，`mfcControlOneMass`）**：

```c
// ModelControl.c: ~195行

// Step1: 位置指令过 4阶低通滤波（截止频率 Kf1）
FCmd[0] = LPF2( LPF2( dPcmd, Kf1 ) )         // 平滑后的位置模型

// Step2: 一阶差分 → 速度模型（再次滤波提升分辨率）
dFCmd[0] = mfcDtrCmdFilter( ... )             // 差分 + 滤波

// Step3: 速度模型一阶差分 × 惯量系数 = 加速度前馈转矩
wk     = MlibMulgain30( dFCmd[0], InvFsft );
TrqRef = MlibMulgain( wk, Kj1 );             // Kj1 ∝ J_model / T_max

// Step4: 方向修正（正/反向摩擦增益 Ktff1/Ktff2）
tffcmd         = MlibMulgain( TrqRef, Ktffcmdx ) + FricCmpTrq;
MFControl->var.TffCmd = MlibLimitul( tffcmd, ... );

// Step5: 速度 FF
VffCmd = MlibMulgain( Vref, Kvff );
```

**物理本质**：`dFCmd[0]` 相当于滤波后位置指令的二阶差分（加速度），乘以 `Kj1`（模型惯量归一化系数）得到前馈转矩。

#### 路径 C：无（MFC 关闭 + 内部模式）

MFC 关闭时（`CurMFCModel == 0`），内部只有速度前馈（`dPosRefi × KdPff`），**没有加速度/转矩前馈**，加减速过程全靠 PI 积分项补偿。

### 7.3 三种模式对比

| 工作模式 | 速度 FF | 转矩/加速度 FF |
|---------|---------|--------------|
| Mechatrolink（上位机） | `NetSpdFFC`（上位机下发） | `NetTrqFFC`（上位机下发） |
| 内部 P2P，MFC 关闭 | `dPosRefi × KdPff`（一阶差分） | **无** |
| 内部 P2P，**MFC 开启** | `VffCmd`（MFC 模型一阶差分 × Kvff） | `TffCmd`（MFC 模型惯量 × 加速度） |

> **注意**：MFC 开启时，`dPosRefi × KdPff` 的速度 FF 被跳过（`BaseControls.c:869` 中 `if CurMFCModel == 0` 的互斥条件）；外部 `NetTrqFFC` 也只在 `MFC 关闭 || MFCFF==TRUE` 时叠加。

### 7.4 信号汇总流图

```
上位机规划轨迹
    │
    ├── NetSpdFFC ──[移动平均]──────────────────→ + SpdFFCx ─→ 速度环 PI 输入
    │
    └── NetTrqFFC ──[移动平均]──────────────────→ + TrqFFCx ─→ 电流环（绕过 PI）

内部位置指令（ProgramJog / TableDrive）
    │
    └── dPosRefi × KdPff ──[LPF]──────────────→ + SpdFFCx ─→ 速度环 PI 输入
              │
              └── MFC（开启时）
                    ├── VffCmd ────────────────→ + SpdFFCx
                    └── TffCmd（J×α）──────────→ + TrqFFCx ─→ 电流环
```

### 7.5 扰动观测器补偿（SpdFBC）

```c
// ExControls.c（DisturbObserver 模块）
SpdFBC = T̂_L / Kv    // 估计负载扰动转矩折算为等效速度补偿
```

估计的负载扰动转矩 $\hat{T}_L$ 折算为速度补偿量叠加到反馈信号，抑制低频扰动（摩擦、重力等）。相关参数：PnB04（观测器增益）、PnB05（观测器反馈增益比）。

## 八、参数整定

### 8.1 用户参数映射

| Sigma-7 参数 | 代码变量 | 含义 |
|-------------|---------|------|
| PnB00 | `loophz` | 速度环带宽 [Hz]（位置控制时=速度增益） |
| PnB01 | `jrate` | 负载惯量比 [%]（负载 J / 电机 J × 100） |
| PnB02 | `pitime` | 速度积分时间常数 [×0.1 ms] |
| PnB03 | `ModeSWSel` | P/PI 切换选择 |
| PnB04 | `ObsJGain` | 扰动观测器增益 |
| PnB08 | `loophz2` | 第 2 增益速度环带宽 |
| PnB09 | `pitime2` | 第 2 增益速度积分时间常数 |
| PnB0E | `KVfbFil` | 速度反馈滤波时间常数 [×0.01 ms] |

### 8.2 整定步骤

**Step 1：估算负载惯量比（PnB01）**
- 离线：从机械设计图纸计算 $J_{load} = \sum(m \cdot r^2 + I)$，填入 PnB01
- 在线：使用惯量自学习功能（Fn009，摆动电机测转矩响应）
- 或：使用 TuneLess 在线估计

**Step 2：设置速度环带宽（PnB00）**
- 理论上限：电流环带宽的 1/3 ~ 1/5（电流环带宽 ≈ 1 kHz → 速度环最大约 200~300 Hz）
- 实际限制：机械谐振频率决定实际上限
- 经验法则：从 20 Hz 开始，逐渐增大，直到出现振动为止，退后 20%

**Step 3：设置积分时间常数（PnB02）**
- 带宽-积分时间经验关系：$T_i \approx \frac{1}{2\pi \cdot f_{bw} / 4} \approx \text{loophz} \times 4\ [\text{ms}]$
- 积分时间过小 → 过冲增大（积分过激进）
- 积分时间过大 → 低频扰动抑制差（积分太慢）
- 典型值：loophz = 40 Hz → PnB02 ≈ 40~80（对应 4~8 ms）

**Step 4：速度反馈低通截止频率**
- 一般设为速度环带宽的 3~5 倍
- 带宽提高时需同步提高，否则相位损失过大

**Step 5：验证**
- 阶跃响应：超调 < 10%，无振荡
- 扰动响应：加减载时速度跌落后恢复时间 < 1/loophz
- 稳态误差：速度控制模式下稳态误差 ≈ 0（积分项消除）

### 8.3 自动整定（TuneLess / One-Parameter Tuning）

安川提供 TuneLess（调整功能）自动设定增益：

- **原理**：在线辨识机械时间常数，通过扩张状态观测器估计 $J$ 和 $T_f$
- **用户操作**：只需设置一个"响应性"等级（PnB00 参数），固件自动计算 Kv、Kvi、陷波滤波器频率

```c
// BaseControlPrmCalc.c: ~58行
// GselNo=5 表示 TuneLess 增益组
TunLessPrm = &(BaseCtrlData->TuneLessCtrl.TuneLessPrm);
Loophz = TunLessPrm->kv2;    // 在线辨识得到的等效带宽
Pitime = TunLessPrm->Ti;     // 在线辨识得到的积分时间
jrate  = TunLessPrm->jrate;  // 在线辨识得到的惯量比
```

## 九、增益切换（GainChange）

## 十一、惯量辨识（Inertia Identification）

### 11.1 理论推导

#### 问题定义

速度环的所有增益（Kv、Kvi、MFC 的 Kj1 等）都与总转动惯量 $J$ 成正比。若 $J$ 未知，增益整定无从谈起。惯量辨识的目标是在线/离线地估计 $J_{load}/J_{motor}$，即负载惯量比 `jrate`。

#### 基本原理：冲量-动量定理

牛顿旋转方程积分：

$$J \cdot \Delta\omega = \int_{t_0}^{t_1} T_{act}(t)\,dt - \int_{t_0}^{t_1} T_{dist}(t)\,dt$$

若能消去扰动项 $T_{dist}$（摩擦、重力），则：

$$J = \frac{\int T_{act}\,dt}{\Delta\omega}$$

直接法的问题：$\Delta\omega$ 需要精确的速度零穿越检测，噪声敏感。

#### 安川的解法：模型比值法（Model Ratio Method）

建立一个与实际速度环**结构相同**的模型系统，使用已知的模型惯量 $J_m$（初始猜测值）：

$$J_m \cdot \Delta\omega_m = \int_{t_0}^{t_1} T_{model}(t)\,dt$$

模型和实际系统接受**相同的速度指令** $\omega_{ref}$，经过**相同的 PI 控制器**，因此理想情况下跟踪同样的速度轨迹：$\Delta\omega_m \approx \Delta\omega$。

两式相比：

$$\frac{J_{actual}}{J_m} = \frac{\int T_{act}\,dt}{\int T_{model}\,dt} = \frac{\text{sum}}{\text{msum}}$$

$$\boxed{\hat{J}_{actual} = J_m \cdot \frac{\sum T_{act}}{\sum T_{model}}}$$

这个比值法的核心优势：
- **消去 PI 动态**：分子分母都通过同样的速度控制律，控制器引入的非线性在比值中被约消
- **消去速度测量**：不需要直接测 $\Delta\omega$，只需积分转矩
- **消去常值扰动**：通过正/反转两次取平均（见下节）

#### 常值扰动消除（正/反转对称法）

对于重力轴等存在常值扰动 $T_g$（固定方向、固定大小）的情况：

- **正转阶段**（加速至峰速再减速到零）：$\int T_{act}^{fwd}\,dt = J\cdot\Delta\omega + T_g \cdot t_{fwd}$
- **反转阶段**（加速至峰速再减速到零）：$\int T_{act}^{rev}\,dt = J\cdot\Delta\omega - T_g \cdot t_{rev}$

若正/反转运动对称（时间相同），则取平均：

$$\frac{1}{2}\left(\frac{\text{sum1}}{\text{msum1}} + \frac{\text{sum2}}{\text{msum2}}\right) \approx \frac{J_{actual}}{J_m}$$

常值扰动被抵消，结果只剩惯量比。

## 十二、与自研方案的对比分析

> 参考来源：`06_myWork/速度环理论推导.docx`

### 12.1 控制器传递函数结构

**自研方案**（串联 PI，显式建模转矩滤波器）：

$$G_{open}(s) = K_{VP}\left(1 + \frac{K_{VI}}{s}\right) \cdot \underbrace{\frac{\omega_{KC}}{s + \omega_{KC}}}_{\text{转矩低通滤波}} \cdot \frac{1}{Js}$$

进一步做两段频率区间的闭环分析：

- **中低频**（$\omega_{KC} \gg s$，滤波器 $\approx 1$）：$G_c(s) = \dfrac{K_{VP}s + K_{VI}}{s^2 + K_{VP}s + K_{VI}}$，目标 $\zeta = 1.1$
- **高频**（积分可忽略）：$G_c(s) \approx \dfrac{K_{VP}\omega_{KC}}{s^2 + \omega_{KC}s + K_{VP}\omega_{KC}}$，目标 $\zeta = 1.4$

**安川方案**：

$$G_{open}(s) = \frac{K_v}{s}\left(1 + \frac{K_{vi}}{K_v \cdot s}\right) \quad\text{（PI 模式）}$$

增益设计时**隐含**假设速度环带宽远低于转矩滤波器截止频率，未显式对滤波器做频域分解。

**差异**：自研方案对转矩滤波器的影响有更严格的分析，给出了从"PI主导"到"滤波器主导"两个频段的阻尼比约束，可以更准确地评估带宽上限。安川方案的工程处理则是要求用户不要把带宽设得太高，依赖经验守则而非解析推导。

---

### 12.2 惯量归一化策略（最核心的结构差异）

**自研方案**：J 保留到 PI 输出阶段，显式相乘：

$$J_{PU2PI} = 2\pi \cdot J \cdot N_R \quad\text{（Q24）}$$

$$\text{VelocityPIOut} = \underbrace{(e_\omega + \textstyle\int e_\omega)}_{\text{先求和}} \times J_{PU2PI} \times K_{VP}$$

用户增益 $K_{VP}$ 的物理含义：直接等于穿越频率 $f_{bw}$（Hz），与 J 无关。J 在最终输出时补入。

**安川方案**：J 预先折叠进 `Kvx`，用户参数直接以 Hz 操作：

```c
Kvx = 2π × ω_max × J / T_max      // J 一次性归一化
Kv  = Kvx × (1 + jrate/100) × loophz / 1000
// 设 loophz=40 等价于带宽40Hz，用户无需知道J的数值
```

| | 自研方案 | 安川方案 |
|--|---------|---------|
| J 出现位置 | PI 输出时乘 | 预归一化进 Kvx |
| 用户参数语义 | $K_{VP} = f_{bw}$（Hz），与 J 分离 | `loophz` = 带宽（Hz），J 被隐藏 |
| J 发生变化时 | 需更新 $J_{PU2PI}$ | 只需更新 `jrate` |
| 透明度 | J 的作用全程可见，适合理解与推导 | J 被封装，更面向工程用户 |

两者最终有效增益**数值完全相同**，差别只是数学分解方式不同。

---

### 12.3 积分器结构与抗饱和

**自研方案**（误差与积分先求和，再统一乘增益）：

```python
Velocity_integ += iq24mpy(VelocityErr, VelocityIGain)   # 先积分误差
VelocityPIOut  = iq23mpy(VelocityErr + Velocity_integ,   # 两者之和
                          iq24mpy(JPU2PI, VelocityPGain)) # 再乘 J×Kp
```

**安川方案**（比例和积分分别计算，增益已含 J）：

```c
PacOut = MlibMulgain( SpdErrP, Kv );              // 比例支路，Kv 已含 J
IacOut = MlibIntegral( SpdErrI, Kvi, Ivar64 );    // 积分支路，Kvi 已含 J
TrqRef = PacOut + IacOut;
```

两者数学上等价，但结构差异对**抗积分饱和**有直接影响：

- 安川方案中 `IacOut` 是独立变量，可精确地被门控冻结（`TrqClamp` 条件积分）或软衰减（`MlibLpfilter1(0, KVintegFil, IacOut)`）
- 自研方案将积分量 `Velocity_integ` 与误差 `VelocityErr` 混合后再乘增益，若要冻结积分，需在 `Velocity_integ` 的更新处加门控，否则饱和解除时会有转矩突变

**自研方案文档未涉及抗积分饱和**，这在实际工程中是不可回避的设计点——转矩限幅几乎在所有加速段都会触发。安川的两套机制（PI 分支条件积分 + P 分支软衰减）可以直接参考移植。

---

### 12.4 速度前馈与 I-P 模式的耦合

**自研方案**：前馈进入"参考"端，参与误差计算：

$$e_\omega = \omega_{FF,raw} - \omega_{fbk}$$

**安川方案**：前馈作为加法项，在误差之外加入：

```c
SpdErrP = SpdRefx × PI_rate - SpdFbFilo + SpdFFC   // FF 在外部
```

当 `PI_rate < 1`（I-P 模式）时，两者**不等价**：

- 安川的 `SpdFFC` 不受 `PI_rate` 衰减，始终以 100% 的权重进入比例输出，保持前馈的动态效果
- 若自研方案引入 I-P 结构而 FF 仍在 $\omega_{ref}$ 内，FF 会被 PI_rate 折减，轨迹跟踪精度下降

结论：**若引入 I-P 结构，FF 必须移到误差外部**，否则 I-P 的指令抑制会同时削弱前馈效果。

---

### 12.5 加速度前馈实现路径

**自研方案**：直接对指令做内部计算：

$$\text{AccelFF} = J_{PU2PI} \times \underbrace{\text{AccFF}_{filtered}}_{\text{指令二阶差分后LPF}} \times \text{InertialFFGain}$$

**安川方案**：三条路径（优先级依次递减）：

1. 外部：上位机通过 Mechatrolink 下发 `NetTrqFFC`（上位机已算好 $J \cdot \alpha$）
2. 内部 MFC：运行模型 PI 仿真，通过模型速度一阶差分间接得到加速度 FF——**规避了对指令做二阶差分**
3. MFC 关闭时：无内部加速度 FF

**差异**：

| | 自研方案 | 安川 MFC |
|--|---------|---------|
| 加速度来源 | 指令二阶差分 → LPF | 模型 PI 速度一阶差分 |
| 噪声特性 | 二阶差分放大量化噪声 | 低通模型天然平滑 |
| 适用场景 | 梯形轨迹（α 恒定段噪声小） | 通用 |
| 需要 J 估计 | 是（`InertialFFGain` 需整定） | 是（模型 `Kj1` 需整定） |

自研方案在梯形轨迹的匀加速段效果与 MFC 相近，但在抖动指令或较高采样量化噪声场合会不如 MFC 稳定。建议在二阶差分之后加更强的 LPF，或改用类似 MFC 的模型方式。

---

### 12.6 定点数 Q 格式

**自研方案**：每个变量明确标注 Q 格式，并给出中间运算的精度变化推导：

```
积分系数:  VelocityIGain  Q24
比例系数:  VelocityPGain  Q15
速度误差:  VelocityErr    Q23
积分量:    Velocity_integ Q23
PI 输出:   VelocityPIOut  Q15  // q23+(q24+q15-q24)−q23 = q15
前馈:      AccelFF        Q15  // ((q24+q17)−q24+q15)−q17 = q15
电流指令:  Qref_pu        Q24
```

**安川方案**：统一用 $2^{24}$ 归一化（速度 `[2^24/OvrSpd]`，转矩 `[2^24/MaxTrq]`），精度管理封装在 `MlibMulgain` / `MlibIntegral` 等函数内部，源码层不显式标注 Q 格式。

自研方案的 Q 格式注释对 DSP/MCU 裸机实现更友好，可以直接验证每个寄存器的精度范围；安川方式更适合跨平台、有库支撑的场合。

---

### 12.7 差异总结与工程建议

| 维度 | 自研方案 | 安川方案 | 建议 |
|------|---------|---------|------|
| 转矩滤波器的频域分析 | ✅ 显式推导，ζ 约束明确 | ❌ 隐含假设 | 自研更严谨，建议保留该分析 |
| I-P 结构 | ❌ 仅串联 PI | ✅ PI / I-P 可选 | 补充 `PI_rate` 参数，减小阶跃超调 |
| 抗积分饱和 | ❌ 未涉及 | ✅ 条件积分 + 软衰减 | **必须补充**，否则调试必遇饱和问题 |
| 惯量归一化 | J 显式在输出相乘 | Kvx 预归一化 | 两者等价，安川方式对用户更友好 |
| 加速度 FF | 指令二阶差分 + LPF | MFC 模型差分 | 建议加强 LPF 或改用模型方式 |
| FF 与 PI_rate 的耦合 | 潜在问题（引入 I-P 时） | 正确解耦 | 引入 I-P 后需把 FF 移到误差外部 |
| 定点 Q 格式 | ✅ 逐级精确注释 | 封装在 Mlib | 自研方式对裸机实现更直接 |

## 十三、速度开环扫频（Easy FFT / Fn206）

### 13.1 概述

安川通过 **Fn206 Easy FFT** 实现机械共振频率的在线检测。其核心思路是向转矩指令注入宽带激励，观测速度响应的频谱峰值，从而定位机械传动链的共振频率，为陷波滤波器参数设置提供依据。

注意这不是经典控制意义上的开环 Bode 图扫描（不测量相位裕度/增益裕度），而是一个**机械共振峰定位器**：
- 激励：转矩扰动（叠加在正常指令上）
- 观测：速度响应频谱 `|ω(jω)|²`
- 提取：共振峰频率 → 陷波滤波器中心频率

速度环仍处于闭环，但注入点在转矩通道，等效于测量 $G_{mech}(j\omega) = \omega/T$（机械子系统），故称"速度开环"扫频。

```
      ▼
转矩指令通道  — 注入扫频转矩(正转 + 反转各一次)

      │
      ▼

      │

      │

```

### 13.4 OnlineFFT.c — 改进型 DFT 算法

#### 13.4.1 为何不用蝶形 FFT

安川使用**逐频点 DFT**，而非标准蝶形 FFT：

- FFT 要求 N 为2的幂次，且输出所有频率 bin（0 到 Fs/2）
- 机械共振通常集中在100~5000 Hz，只需计算关心的频率段
- 逐频点 DFT 复杂度 O(N×M)（M = 关心的bin数），可跳过不关心的频率
- 无需 bit-reversal 重排，嵌入式实现更简单
- sin/cos 查找表（`MlibFASTSINS16`）补偿了浮点运算的开销

#### 13.4.2 核心计算

`fftAnalyzeCalc()` 对每个频率 bin k 计算 DFT：

$$A(k) = \sum_{n=0}^{N-1} a(n) \cdot e^{-j2\pi nk/N}$$

```c
for (k = Fmin; k <= Fmax; k++) {
    Re = 0; Im = 0;
    for (n = 0; n < N; n++) {
        theta_idx = (n * k) % N;          // 相位索引，映射到查找表
        Re += a[n] * cos_table[theta_idx];
        Im += a[n] * sin_table[theta_idx];
    }
    spectrum[k] = Re*Re + Im*Im;          // 功率谱（不开方，节省计算）
}
```

#### 13.4.3 防溢出动态归一化

```c
smax = max(|a[n]|);                       // 找采样序列最大幅值
scale = smax / REGULAR_SFT;              // 动态缩放因子
// 在 DFT 累加前用 scale 对 a[n] 归一化，防止 N 次累加溢出
// 功率谱乘以 scale² 补偿回来
```

#### 13.4.4 峰值检测与合并

```c
// fftSpectrumPeakDetect(): 维护 top-5 峰值列表（按幅值排序）

// fftSpectrumPeakCollect():
//   将频率间距 ≤ ±100 Hz 的相邻峰合并为一个峰
//   避免同一共振被宽峰重复报告
//   最终输出 top-3 共振频率 + 1 个反共振频率

// 通过/失败双阈值判定:
//   峰值 > MINIMAM_SPECTRUM            (绝对阈值，排除噪底)
//   AND
//   峰值 > 平均谱值 × Pn464[%]         (相对阈值，排除平坦噪声)
```

### 13.6 与经典开环 Bode 图的区别

| 特性 | 安川 Easy FFT | 经典开环 Bode 图 |
|------|--------------|-----------------|
| 激励信号 | 宽带转矩扰动（类白噪声/chirp） | 单频正弦扫描 |
| 速度环状态 | 闭环（转矩通道注入） | 断开速度环 |
| 输出 | 共振峰频率（功率谱峰值） | 完整增益/相位 vs 频率曲线 |
| 测量目标 | 机械共振定位 | 环路增益裕度、相位裕度 |
| 电机运动 | 有实际转动（受速度环保护） | 通常需要人为限位 |
| 实时性 | 在线，数秒完成 | 通常离线，耗时较长 |
